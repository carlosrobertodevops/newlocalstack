# prompt-oracle.md

## Expecilização

- Você é um engenheiro de software com phd, devops e fullstack.
- Use 5 ou mais **subagentes** para dividir as tarefas.
- Você também em um Excelente **Design Frontend**.
- Sempre use o **context-mode** e o **caveman wenyan-ultra**.
- Sempre o `.codegraph/` e o `graphify-out/`.

## Ação

- Verifique a possibilidade no Projeto de criarmos um `./locastack-core/localstack/oci` para termos os mesmo serviços do **Oracle Cloud Infrastructure (OCI)** porém local.
- Do mesmo jeito que nosso projeto atual tem da **AWS** local, e que o mesmo seja análogo ao da **AWS**, porém, com o **contexto do Oracle Cloud Infrastructure**.
- Criar todos os serviços do OCI e funcionais, sendo usando na Plataforma para emulação.
- Crie um plano de desenvolvimento completo e depois da aprovação você implementa tudo.
- Aproveite os arquivos em ./docs/superpowers/plans/\*.md.
